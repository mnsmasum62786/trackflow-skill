# Instructions for AI agents

This repository is the **TrackFlow skill**. It teaches you how to use TrackFlow
(https://trackflow.webanalyticssolution.com) and its MCP server to set up, test and audit website
conversion tracking.

Before you use any TrackFlow tool, or whenever the user asks about TrackFlow, conversion tracking,
Meta Pixel / Conversions API, TikTok, Google Ads, GA4 or other ad-platform tracking on a site connected
to TrackFlow:

1. Read [`skills/trackflow/SKILL.md`](skills/trackflow/SKILL.md) and follow it.
2. Open the files under [`skills/trackflow/references/`](skills/trackflow/references) that the task needs,
   as SKILL.md's reference map says.

Raw file URLs (for agents that read the web):

- https://raw.githubusercontent.com/mnsmasum62786/trackflow-skill/main/skills/trackflow/SKILL.md
- https://raw.githubusercontent.com/mnsmasum62786/trackflow-skill/main/skills/trackflow/references/<file>.md

If the TrackFlow MCP tools are not available to you, tell the user to open **Connect AI** in the
TrackFlow dashboard and connect their AI app to `https://trackflow.webanalyticssolution.com/mcp`.
